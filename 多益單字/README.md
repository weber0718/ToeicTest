# 🎯 TOEIC Vocab Master｜多益單字智慧測驗與錯題本系統

這是一個完整的多益（TOEIC）單字學習與測驗網站，採用 **Node.js 前後端分離架構（REST API + JSON 資料庫持久化）**，同時內建 Windows 免安裝啟動與離線備援機制。

---

## ✨ 功能特色

1. **🔐 學員帳號登入與註冊系統**
   - 支援新學員註冊、登入、切換帳號與修改目標多益分數（如 600 / 750 / 860 / 950 分）。
   - 內建一鍵體驗示範帳號（帳號：`demo`／密碼：`123456`），預載測驗歷史與錯題範例。
   - 密碼經 `SHA-256` 加鹽雜湊後安全儲存於伺服器端資料庫 [`data/db.json`](./data/db.json)。

2. **📝 四選一選擇題測驗（即時解析 & 自動收錄錯題）**
   - **4 種出題模式**：英翻中、中翻英、**多益 Part 5 例句挖空填空**、綜合混合出題。
   - **智慧干擾項生成**：優先挑選相同詞性（`n.`, `v.`, `adj.`）的單字作為選項，貼近真實多益考題。
   - **作答後即時詳解**：顯示正確答案、音標、詞性、同義字與完整多益商務例句中譯，並自動發音。
   - **自動錯題紀錄**：答錯題目於測驗結束時自動寫入您的個人「錯題本」並累計錯誤次數。

3. **🎧 聽力／拼字填空測驗**
   - 支援 **正常語速 (1.0x)** 與 **慢速播放 (0.75x)**，可切換 **美式發音 (en-US)** 與 **英式發音 (en-GB)**。
   - 結合中文釋義與多益例句挖空上下文，訓練聽音辨字與拼寫能力。
   - 提供「💡 提示首尾字母」輔助功能；拼錯之單字同樣自動收錄至錯題本。

4. **📕 錯題本專區與熟練度追蹤 (Mastery Tracking)**
   - 詳細記錄每個錯題的 **累計答錯次數**、**最後答錯模式與時間**、**熟練度星級 (`★☆☆` ~ `★★★`)**。
   - **專項重測機制**：可一鍵啟動「🔥 待加強錯題：四選一重測」或「🎧 待加強錯題：聽力拼字重測」。
   - **自動升級熟練**：在測驗中針對錯題**連續答對 3 次**，系統會自動將該單字標記為「⭐ 已熟練掌握」（亦可手動切換或移除）。
   - **個人記憶筆記**：可為每個錯題撰寫專屬記憶口訣或文法筆記，即時同步至伺服器資料庫。

5. **🗂️ 3D 互動單字卡 & 自訂新增單字題庫**
   - **3D 翻轉單字卡**：支援點擊或鍵盤快捷鍵（`Space` 翻面、`←`/`→` 切換、`S` 發音、`B` 加入錯題本）。
   - **完整題庫搜尋與篩選**：內建 **80 個高頻多益核心單字**（涵蓋商務合約、財務會計、人事職場、行銷銷售、旅遊交通、科技製造六大主題，以及 600 / 750 / 860 分三階段難度）。
   - **自訂新增單字**：可隨時新增自己的多益單字、例句與翻譯至伺服器資料庫，並立即納入所有測驗與單字卡中。

## 🚀 如何啟動網站

### 方式一：雙擊 `start.bat` 一鍵啟動（最推薦）
直接雙擊專案目錄下的 [`start.bat`](./start.bat)：
- 若電腦已安裝 Node.js，會自動執行 `node server.js` 啟動後端伺服器。
- 若尚未安裝 Node.js，會自動使用內建的 [`server.ps1`](./server.ps1) 啟動相同規格的本地端 REST API 伺服器，並自動打開瀏覽器前往 `http://localhost:3000`。

### 方式二：使用 Node.js 指令啟動
```bash
npm start
# 或直接執行（免安裝額外套件即可運作）：
node server.js
```
啟動後請在瀏覽器開啟：`http://localhost:3000`

### 方式三：直接開啟前端網頁
您也可以直接用瀏覽器雙擊打開 [`public/index.html`](./public/index.html)，前端內建自動偵測機制，若未啟動後端伺服器會自動切換為瀏覽器本地資料庫模式（LocalStorage），所有功能皆可正常使用。

## 📁 專案目錄結構

```text
多益單字/
├── package.json          # Node.js 專案設定檔
├── server.js             # Node.js 後端伺服器與 REST API 實作
├── server.ps1            # Windows PowerShell 備援 REST API 伺服器（免裝 Node 亦可啟動）
├── start.bat             # Windows 一鍵啟動腳本
├── data/
│   ├── words.json        # 內建 80 個高頻多益核心單字題庫（含音標、例句、中譯、分類、難度）
│   └── db.json           # 伺服器端資料庫（儲存使用者帳號、錯題本、筆記、測驗歷史、自訂單字）
└── public/
    ├── index.html        # 前端主頁面（SPA 多分頁設計）
    ├── styles.css        # 現代化響應式介面與 3D 單字卡動畫樣式
    ├── words-data.js     # 前端預設題庫快取
    └── app.js            # 前端核心邏輯（認證、四選一、聽力拼字、錯題本、語音合成 TTS）
```
